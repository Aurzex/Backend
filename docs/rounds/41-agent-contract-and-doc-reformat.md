# 第四十一轮记录 — 项目级契约固化与全盘文档重构

## 0. 一句话
以根目录 `AGENTS.md` 固化项目级规范,并据此对全部 Markdown 文档执行格式、状态与语体的全盘清洗;文档库的权威口径自本轮起由该契约确立。

## 1. 任务背景
2026-10-02 提出两项要求:其一,建立项目级 AI 协作规范,使后续会话无需人类重复输入提示词;其二,依据该规范对现有全部文档执行格式清洗与内容重构。此前多轮增量编辑造成三类问题:同一事实在多个文件各写一遍、人工维护的计数与口径漂移、状态用词不统一。

## 2. 契约固化
| 动作 | 结果 |
| --- | --- |
| 新建 `AGENTS.md` | 写入项目知识库维护与迭代规范(核心任务、加载协议、体例 9 条红线、收尾 SOP、输出禁忌、正文语体、三库定位) |
| `README.md` 首行 | 插入引导注释,声明进入任务前须读取 `AGENTS.md` |
| `docs/README.md` 文档体例节 | 改为指向 `AGENTS.md` 的指针 + 两库分工 + 例外清单,不再重复条文(单一事实源) |

## 3. 执行方案与中断
原方案为按字节切分 14 个互不重叠切片并行处理全部 55 个文件。该批子代理在运行约 13 分钟后全部异常终止,原因为供应商侧鉴权与余额错误(HTTP 401 与 402),非任务本身失败。终止时已完成的编辑质量可用(示例:`README.md` 的去口语化、箭头归一、表格分隔行改写均正确),故保留其成果,改由总控以可审计的脚本化变换补齐余下部分。
