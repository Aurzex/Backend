# 第三十六轮记录 — 凡是往 Kitten4 写名字的地方,都得过"编辑器词汇"判据

## 1. 缘起

rounds/35 修掉 `theatre.groups` 后,角色能显示了;本轮继续收口**"编辑器不认识 ⇒ 剔块/清影子"**这条保真缺口
(rounds/34 §4nonies 的刻意取舍)。先量化,再定点修。

## 2. 发现一:块路径的**单候选分支**漏了词汇判据

`reverse_kind` 的歧义分支(`Some(candidates)`)是按"编辑器认识的优先"挑的,
但**单候选分支**(`Some([only])`)**直接取那一个候选** —— 而表里的 Kitten 侧名字是 **Kitten3 口径**。

实测(词汇表 349 条 + 平台语料计数,判据是"平台上真实作品用什么"):

| 名字 | 编辑器注册表 | 平台 40 件 Kitten4 语料出现次数 |
| --- | --- | --- |
| `text` | ✓ 认识 | **1338** |
| `get_split_options` | ✗ 不认识 | **0** |

⇒ KN `text`(KN 语料 11 件里 463 次)被映射成 `get_split_options` ✗ ⇒ 写出阶段当"编辑器不认识"**剔掉**。
两个真作品的报告里,`get_split_options` 占了被剔块的大头(98 + 116 块)。

## 3. 发现二:影子路径是**同一个 bug**

影子 XML 的类型由 `untransform_shadow_xml` 反演,它同样"只取单候选、不看词汇表" ⇒
KN `text` 的影子被写成 `get_split_options` ⇒ 被**清空**(170 + 178 条)。
**块与影子必须共用同一套取名规则** —— 这是本轮最值得记的一条。

## 4. 修法

新增 `pick_single_reverse_name(kn_kind, candidate)`(块与影子共用):

1. 候选编辑器认识 ⇒ 用它;
2. 否则 KN 名编辑器认识 ⇒ **保留 KN 名**(名字与形状都不用动,正向解析最稳);
3. 否则照旧给候选 ⇒ 写出阶段剔除/清空并逐类报告(不在这里静默改名)。

块路径:`Some([only]) => pick_single_reverse_name(...)`;影子路径:单候选同样过它
(多候选=歧义时影子保持原名:挑形状是块侧的事)。

## 5. 效果(两件真作品 A/B,同代码路径前后各跑一次)

| 作品 | 剔块(前→后) | 清影子(前→后) |
| --- | --- | --- |
| `Node VM v3`(328981781) | 527 → **429** | 174 → **4** |
| `now`(273988379) | 415 → **286** | 224 → **46** |
| 合计 | 942 → 715 | 398 → 50 |

- `get_split_options` 的块与影子**全部消失**(名字回到编辑器认识的 `text`);
- 反向定义体预算门实测 **3237 → 3193**(门已收紧到 3193,只许变小);
- 实机复验(无头 Chromium + 线上 Kitten4「打开本地作品」):对照(能读的反编译产物)**52** 块、
  `now` **14** 块、`Node VM v3` **6** 块,角色列表都在(`新角色1`/`新角色`/`Execute`/背景)⇒
  改名之后**编辑器照样打得开**,不是拿"能打开"换"少几块"。

## 6. 仍未解决(有证据表明**不可映射**,不是我们偷懒)

KN(Neko)专有块族在 Kitten4 注册表里**没有对应名**,平台 Kitten4 语料里也**一次都不出现**:

`temporary_list`(285+)、`script_variables`/`_param`/`_value`(→212)、`traverse_number*`、
`self_listen_*`/`self_broadcast_with_param`、`procedure_boolean`、`self_text_effect_color`、`color_size_slider`。

它们继续走"剔除 + 逐类报告"。要做成"语义降级"(例如用列表变量模拟 `temporary_list`)属于**改语义**,
风险高,列为待议(要做得先有"降级后行为等价"的判据)。

## 7. 门

`cargo fmt --check` ✓ / `cargo clippy --all-targets -- -D warnings` ✓ / `cargo test` 全绿(单测 102 过 / 0 红)。

> **教训**:表是 Kitten3 口径 ⇒ **凡是往 Kitten4 写积木名字的地方(块、影子,以及将来任何新的写出点)
> 都必须过"编辑器词汇"判据**;漏一处就会安静地丢内容(块被剔、影子被清),而且只在报告里看得见。
